# Getting help with AppFiler

AppFiler is a volunteer project, so help comes from the maintainer and other users in their spare time. Here's where to go so your question reaches the right place.

## Found a bug?

Open an [issue](../../issues) and include:

- the AppFiler version (Settings → About in the app)
- your phone model and Android version, and the OS (for example GrapheneOS, and its build number)
- what you did, what you expected to happen, and what happened instead
- screenshots if they help, with anything personal blurred out

Check the existing issues first. If someone has already reported the same problem, add your details to that issue rather than opening a new one.

## Have a question or an idea?

Use [Discussions](../../discussions) for questions about using the app, ideas for features, and sharing your rule files. Ideas that gather support there become issues.

You'll also find people using AppFiler in the GrapheneOS forum.

## Found a security problem?

**Don't report it in public.** Use GitHub's private "Report a vulnerability" button on this repository's Security tab. See [CONTRIBUTING.md](CONTRIBUTING.md#reporting-a-security-problem) for details.

## What's supported

AppFiler is developed and tested on GrapheneOS, and that's where support is best. It should work on any Android 8.0 or later, and reports from other ROMs and stock Android are welcome, but fixes for them depend on someone being able to test there.

Only official builds are supported, the ones signed with the key whose fingerprint is published in the [README](README.md#official-builds). If you installed a copy from somewhere else, please check its signature first.

## Please don't

- send questions by email or private message. Answers given in public help the next person with the same question.
- post your full app list or exported label file in public. It says a lot about you. If a file is needed to reproduce a problem, cut it down to the lines that matter.
